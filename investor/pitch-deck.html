Problem

Manual trading still runs on pre-computer rules

01
Exchange UIs are stuck in the past
Exchange interfaces are too basic; pro platforms (Hummingbot, HaasOnline) are overloaded. No middle ground for a serious retail trader.
02
AI in trading is a bolt-on, not a tool
Today's solutions put an AI chat next to the chart. Nobody ships an AI that sees positions, writes strategies and supervises execution.
03
The trader sleeps — the market doesn't
A signal missed overnight = a trade lost or a position left unguarded. Crypto runs 24/7.
04
Speed decides — clicks cost money
While the trader hand-calculates SL/TP, the setup has already moved. Every manual click is a built-in loss.
05
A double barrier: cost & trust
$15–100/mo subscriptions before any result — plus handing API keys to a third-party service. 3Commas, 2022 — $22M of customer losses.
Solution

X·Cockpit — the cockpit + an AI co-pilot

A free, open-source trader cockpit with an AI assistant that writes, tests and runs strategies 24/7. No subscription barrier — we monetise through exchange commissions.

🎯
1 · X·Cockpit UI — one interface to every CEX
Chart, positions, orders, history & controls on one screen. Auto TA markers, dynamic orders, order book synced to the price axis. MVP: Bybit, Binance, OKX → all major CEX via a CCXT-compatible layer → DEX.
🤖
2 · AI Assistant — a staff co-pilot
Helps write and optimise strategies. Semi-automatic mode: the trader decides, the AI builds the strategy, supervises execution and picks the entry moment.
⚡
3 · Server-side automation that never sleeps
Strategies and dynamic orders run 24/7 on our backend. “AI works at night, the human reviews in the morning” — a bridge between manual and blind automation.
🛡
4 · Advanced orders out of the box
Dynamic orders recompute automatically. The position is protected against loss the moment it opens — no chasing SL/TP by hand.
🔑
5 · Open Source + keys never with us
Transparent code, zero entry barrier — users see what works before they pay. API keys stay with the user or the exchange; the platform never gets access. Self-hosted: keys local. Cloud: via an exchange broker sub-account.

How It Works

You choose your own level of trust

🔒 Two connection modes
  • Direct — client calls the exchange API; keys stored locally, Zero Trust.
  • Via our server — 24/7 execution through a broker sub-account; the key never leaves the exchange.
🤖 Two AI options
  • Local — open-source LLM (Ollama / Llama / Mistral); full privacy.
  • Cloud — ChatGPT, Claude, Gemini; more powerful, no hardware needs.

Roadmap

Every iteration ships a working product

Each new iteration extends the previous one rather than replacing it.

Bybit, OKX, Binance · X·Cockpit UI (chart + orders + TA markers + dynamic orders + order book) · simulation + genetic optimiser · AI assistant prototype · OSS launch (GitHub, HN, Reddit) + iFX EXPO Dubai. M10–12: first revenue from the first trade (Affiliate ID, fee share 25%).
Iteration 2 — Server mode13–18 mo
+ Hyperliquid · 24/7 server-side execution + API for 3rd-party devs · AI assistant v1, Telegram bot · reach $10M+/mo on Bybit → Broker Master application. Pre-Seed end: 105–420 active traders, ARR run-rate $15–60K.
Iteration 3 — Global + Seed deploy19–24 mo
Seed $1.8M closed by M18. Bybit Broker Master + AI-agent soft-launch (M22–24) → $50/mo subscriptions · mobile client · EU expansion (MiCA). M24: 1,680 active, MRR $39K, ARR $464K.

Raise Series A on proven unit economics · US exchanges (Coinbase, Kraken, Gemini) · AI assistant v3 (autonomous agents) · LatAm + SEA. 8,040 active, ARR $7.14M (Bull+Scale $11.46M).
