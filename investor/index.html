Problem & Solution

Exchange notation from the pre-computer era. Professional platforms overloaded, demanding a developer's skillset. AI trading tools haven't reached maturity. Pay blindly before any result — hand your API keys to a third party.

Open Trader is a free, open-source trading terminal with an AI assistant. No paywall to start — we monetise through exchange commissions.

Business Model
Phase 1 From M10, revenue from trade #1 via the exchange API Broker ID — entry-tier fee share (~20–30% of fees), no minimum volume, on the user's own keys. Covers new and existing exchange users.
Phase 2 Tier rebate rises to up to 45–50% as volume grows.
