The roadmap

Four products, built in sequence. Each one is a foundation for the next.

  1. 01 In development

    The Exchange Scratcher

    An open-source trading terminal that connects to major crypto exchanges via their public APIs. Configure your accounts once and trade across Bybit, Binance, OKX, and more from a single purpose-built interface — one you can audit, fork, and fully control. No subscriptions, no proprietary lock-in, no black boxes.

    • ✈
      Trader Cockpit Chart, order book, positions, and open orders on one screen. TA markers calculated automatically; orders linked to indicators and updated in real time.
    • 🕑
      24/7 Backend Server Run strategies continuously without keeping a device online. Server-side execution with isolated environments and scoped API key access.
    • 📊
      Strategy Marketplace & Copy-trading Browse, copy, and publish trading algorithms. A live performance leaderboard lets you evaluate strategies before committing capital.
    • Trader Cockpit
    • 24/7 Server
    • Strategy Marketplace
    • Multi-exchange API
    • Open source
    Full product details → View on GitHub →
  2. 02 Planning

    The Scratcher Agent

    An AI assistant purpose-built for trading strategy development. The Agent writes and debugs strategy code, tunes parameters against historical data, and interprets backtest results — with every recommendation logged and explainable. Runs locally via Ollama, Llama, or Mistral for complete privacy, or connects to cloud LLMs when raw capability matters more than isolation. You choose the trust boundary.

    • Local LLM
    • Cloud AI
    • Strategy development
    • MCP integration
    • Open source
  3. 03 Planning

    The Scratcher Wallet

    Self-custody done without compromise. A clean, multi-chain wallet designed for users who want to understand exactly what they are signing — not a simplified experience that obscures on-chain details, but one that makes them readable. Built to work alongside the Exchange Scratcher and share the same Zero Trust design principles.

    • Self-custody
    • Multi-chain
    • Transparent signing
    • Open source
  4. 04 On the horizon

    The Scratcher DEX

    The logical conclusion of the stack: a fully decentralised exchange where trades settle peer-to-peer and the order book lives on-chain. No custodian, no single point of failure, no counterparty risk beyond the smart contracts themselves — which will be open source and independently auditable. The long-term foundation for everything built before it.

    • On-chain order book
    • Peer-to-peer settlement
    • Non-custodial
    • Open source

More from the project

Additional work running alongside the core roadmap.

Crypto Education

Technical writing on how crypto actually works — consensus mechanisms, key management, DeFi primitives, and the details that most documentation glosses over. Written for engineers and builders, not for traders chasing momentum.

🔑

IP Reserve License IPRL

A license for founders building in the open before incorporating a company. Publish open-source code today and retain your intellectual property as founder's capital for tomorrow — without restricting how anyone uses the software.

🔧

Useful Tools

Focused utilities that emerge from building the larger products — key generators, transaction decoders, fee estimators, and other standalone tools that are generally useful to the crypto developer community.
