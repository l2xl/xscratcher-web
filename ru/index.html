The Scratcher Project — open-source инициатива по созданию криптоинфраструктуры, где уровень доверия выбираете вы. От торгового терминала с интерфейсом кабины пилота до AI-ассистента, который помогает строить стратегии — каждый инструмент проверяем, форкаем и полностью под вашим контролем.

Зачем мы это строим

Биржевые UI слишком просты. Профессиональные платформы слишком сложны. AI меняет всё — а текущие инструменты не успевают.

01

Биржевая торговля маргинализирована в IT-сообществе

Миллионы инженеров могли бы торговать, если бы инструменты уважали их навыки. Биржевые UI упрощены до предела; профессиональные платформы требуют глубокой экспертизы.

02

AI-революция уже здесь

Всё, что можно делать на компьютере, скоро будет делаться через AI. Текущие торговые решения не предоставляют такого функционала — пока.

03

Трейдер спит — рынок не спит

Рынок работает 24/7. Пропущенный сигнал ночью — упущенная сделка или незащищённая позиция. Ручной мониторинг физически невозможен.

04

Платить приходится до того, как понятно — работает ли

Большинство решений требуют подписки $15–100/мес до получения реального результата. Барьер входа отсекает тех, кто мог бы стать лояльным пользователем.

Дорожная карта

Два продукта в MVP. Каждый — фундамент для следующего.

  1. 01 В разработке

    The Exchange Scratcher

    Open-source торговый терминал, подключаемый к криптобиржам через API. Trader Cockpit-интерфейс, автоматический технический анализ, динамические ордера и полная изоляция от биржи — всё на одном экране. Без подписок, без чёрных ящиков.

    • ✈
      Trader Cockpit График, ордербук, позиции и ордера на одном экране. Маркеры ТА рассчитываются автоматически; ордера привязаны к индикаторам и обновляются в реальном времени.
    • 📚
      DataHub Унифицированный слой данных для агрегации, нормализации и распределения рыночных данных между биржевыми подключениями.
    • Trader Cockpit
    • DataHub
    • Multi-exchange API
    • Open source
    Подробнее о продукте → GitHub →
  2. 02 Планирование

    The Scratcher Assistant

    AI-ассистент для разработки торговых стратегий. Пишет, отлаживает и оптимизирует код стратегий. Работает локально через Ollama, Llama или Mistral для полной приватности, или подключается к облачным LLM, когда мощность важнее изоляции. Уровень доверия выбираете вы.

    • Локальная LLM
    • Облачный AI
    • Разработка стратегий
    • Open source

  1. 03 На горизонте

    The Scratcher Wallet

    Web3-кошелёк с самостоятельным хранением, интегрированный с The Exchange Scratcher и децентрализованными биржами. Те же принципы Zero Trust — ключи локально, транзакции прозрачны, код открыт.

    • Web3 кошелёк
    • Интеграция с DEX
    • Self-custody
  2. 04 На горизонте

    The Scratcher BlockChain · StableCoin · DEX

    Логическое завершение стека: полностью децентрализованная биржа со своим блокчейном и стейблкоином. Peer-to-peer расчёты, ончейн-ордербук, без кастодиана — open source и независимый аудит.

    • Блокчейн
    • StableCoin
    • DEX
