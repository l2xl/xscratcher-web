X·Cockpit

Open-source платформа для торговли на криптобиржах с Trader Cockpit-интерфейсом и AI-ассистентом. Ваши ключи остаются локально, код проверяем, уровень доверия — ваш выбор.

GitHub → Дорожная карта

Проблема

Биржевые UI слишком просты и ограничены — потери встроены в UX. Профессиональные платформы (Hummingbot, HaasOnline) перегружены и требуют высокой экспертизы. Существует огромное количество IT-специалистов, которые никогда не станут сразу платить, но могли бы попробовать торговать, если бы была такая возможность.

01

Трейдер спит — рынок не спит

Рынок работает 24/7. Пропущенный сигнал ночью — упущенная сделка или незащищённая позиция. Ручной мониторинг физически невозможен.

02

Скорость решает — ручная торговля с традициями из до-компьютерной эпохи

Пока пользователь вводит параметры вручную — условия сделки упущены. Ручная торговля = встроенные потери на каждой сделке.

03

Платить приходится до того, как понятно — работает ли

Большинство решений требуют подписки $15–100/мес до получения реального результата. Барьер входа отсекает тех, кто мог бы стать лояльным пользователем.

Решение

X·Cockpit — open-source платформа для торговли на криптобиржах с Trader Cockpit-интерфейсом и The Scratcher Assistant. Open source означает бесплатный вход и аудиторию, где пока нет конкурентов.

Как это работает

│                                                                              │
│ [ X·Cockpit ]◄──────────►[ AI-ассистент ]◄───► локальная модель              │
│           │                                    │          Ollama / Llama     │

└───────────│────────────────────────────────────│──────────────────────────────┘
            │ биржевой API                       │ LLM API
            │                                    │
     ┌──────┴──────┐                             │
     │             │                             ▼
  напрямую   через наш                    [ AI-серверы ]
             сервер                       ChatGPT, Claude,
                                             Gemini, ...
             │
             ▼
      [ Биржи ]
     Bybit, Binance...

Trader Cockpit → биржа: Напрямую — клиент обращается к бирже по API; ключи хранятся локально, Zero Trust. Через наш сервер — для серверного исполнения торговых стратегий 24/7.

AI-ассистент → модель: Локальная оркестрация — open-source LLM (Ollama / Llama / Mistral); контролирует приватность, проверяет внешние запросы. Облачные AI-серверы — ChatGPT, Claude, Gemini; используйте всю мощь AI, без требований к железу.

«Выбираешь уровень доверия сам: хочешь — всё локально. Хочешь — облако.»

Trader Cockpit

Интерфейс как кабина пилота: график, позиции, ордера, история и управление — на одном экране. После подключения биржи через API платформа мгновенно отображает всё, что компьютер способен посчитать и автоматизировать.

📈
Автоматический расчёт маркеров ТА

Уровни поддержки и сопротивления, тренды, каналы — рассчитываются и наносятся на график автоматически. Ничего не нужно настраивать вручную.

🔗
Ордера привязаны к маркерам ТА — и динамические по умолчанию

Ключевая особенность: работающая «из коробки» связь между маркерами технического анализа и управлением ордерами. Параметры ордера вычисляются на основе привязанного индикатора и пересчитываются автоматически при его изменении.

Динамический лимитный ордер — лимитная заявка, цена которой автоматически следует за значением выбранного индикатора.

Catch the Tail — оптимальное исполнение при резком ценовом движении: ордер выбирает наилучший режим входа, пока отклонение цены не вышло за допустимый диапазон.

Умный трейлинг-стоп — трейлинг-стоп ордер, параметры которого автоматически подстраиваются под рыночные условия: меньший порог активации, пока цена близка к цене открытия, и умная корректировка порога в зависимости от актуальной волатильности.

📰
Ордербук синхронизированный с графиком котировок

Глубина рынка и текущий спред всегда в контексте ценового графика — без переключений между вкладками. Максимально удобная и полная визуализация «из коробки».

🌐
Кумулятивное отображение с данными от нескольких бирж

Подключите несколько бирж по API — маркеры ТА и рыночный контекст отображаются в едином торговом пространстве.

🔒
Изоляция от биржи

Ордера могут не отправляться на биржу «до последнего момента», исключая игру биржи против позиции трейдера.
