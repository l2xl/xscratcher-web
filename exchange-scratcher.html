The Exchange Scratcher

The open-source trading terminal for crypto. Connect to major exchanges, trade from a purpose-built cockpit interface, and run strategies around the clock — without giving up custody of your keys or control of your data.

View on GitHub → Back to roadmap

Trader Cockpit

Most trading interfaces force you to split attention across multiple tabs: a chart in one window, the order book in another, positions somewhere else. Trader Cockpit puts everything on a single screen — chart, order book, open positions, pending orders, and trade history in one coherent workspace. No context-switching, no missed signals.

📈
Automatic TA markers

Support and resistance levels, trend lines, and other technical analysis markers are calculated and rendered on the chart automatically. Nothing needs to be configured manually; the relevant context is always visible.

🔗
Orders linked to indicators

Orders can be bound directly to TA markers. When an indicator updates, the linked order parameters recalculate automatically — keeping your positions anchored to the current market structure rather than a static price you entered hours ago.

⚡
New order types

Dynamic Limit Order — a limit order whose price follows a selected indicator in real time.
Catch the Tail — optimal entry execution during sharp price moves: the order selects the best entry mode while the deviation stays within an acceptable range.

📰
Synchronised order book and spread

Market depth and the current spread are displayed alongside the chart, aligned to the same price axis. The full market picture is always in context — no tab-switching required.

🌐
Unified multi-exchange view

Connect multiple exchanges via API and see TA markers and market context in a single trading environment. Aggregate liquidity, compare spreads, and execute from one place.

Standalone Application

The Exchange Scratcher is a standalone desktop and web application — free to download and use, with no subscription or registration required. Exchange API keys are stored locally on your device. The application communicates directly with exchange APIs; there is no intermediary server that can access your account or act on your behalf.

The application is open source under the IP Reserve License. The full source is available to read, audit, build, and fork. You are never dependent on our infrastructure to run it.

Zero Trust by Design. We build the system so that even we cannot act on your behalf. Your exchange keys never leave your local environment in the standalone application. Every action the software takes on your account is initiated by you, and every algorithm that executes it is in the open-source codebase.

Exchange support: MVP launch on Bybit. Roadmap includes Binance, OKX, and Hyperliquid.

24/7 Backend Server

Crypto markets operate continuously. A strategy running only while your laptop is open will miss signals, leave positions unprotected, and execute inconsistently. The Exchange Scratcher backend server runs your strategies around the clock — no open device required.

🔒
Scoped API key access

The server requests only the permissions a strategy needs to execute — typically trading permissions only. Withdrawal access is never required or requested.

🔄
Isolated strategy environments

Each strategy runs in an isolated environment. A failing or misconfigured strategy cannot affect the execution of others.

🏠
Self-hosted option

Deploy the backend server on your own infrastructure. Full source is available; no proprietary components, no vendor lock-in.

Cloud or self-hosted. Use our managed infrastructure or run the server yourself. Both options give you the same codebase and the same guarantees — the difference is who operates the hardware.

Strategy Marketplace & Copy-trading

The Exchange Scratcher includes a strategy marketplace where developers can publish and monetise trading algorithms, and users can discover and copy them. A live performance leaderboard shows verified results, so you can evaluate a strategy's track record before committing capital to it.

📋
Transparent leaderboard

Live performance data for published strategies: return, drawdown, trade count, and time in market. Ranked by verified results, not self-reported figures.

👥
Copy-trading

Subscribe to a strategy and have its trades mirrored to your account automatically. You control the position sizing; the strategy author controls the logic.

💰
Revenue share for authors

Developers who publish strategies earn a share of subscription revenue from users who copy them. Build a strategy once; earn from it continuously.

🔎
Open source, inspectable code

Strategy code published to the marketplace is open for inspection. Users can review what a strategy does before running it on their account.

The Scratcher Agent

The Exchange Scratcher is designed to work alongside The Scratcher Agent — an AI assistant for building and refining trading strategies. The Agent integrates directly with the terminal through an open MCP (Model Context Protocol) interface, giving it access to live market data, backtest results, and your strategy configuration.

The Agent runs locally via Ollama, Llama, or Mistral for complete privacy, or connects to cloud LLMs when more capability is needed. Every recommendation it makes is logged and explainable — no opaque decisions, no black-box outputs.
